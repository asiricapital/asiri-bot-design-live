# دراسة المشاريع الكبرى — Asiri Intelligence OS v6.5

## الهدف

دراسة الأنماط المعمارية والوظيفية في المشاريع المالية والمفتوحة المصدر الكبرى، ثم تحويل المبادئ المناسبة إلى تصميم أصلي لمنصة Asiri Capital. لا يتم نسخ كود أو واجهات أو أصول بصرية من هذه المشاريع.

## 1. OpenBB — طبقة البيانات الموحدة

### المبدأ المفيد
- ربط مصدر البيانات مرة واحدة ثم استهلاكه عبر واجهات متعددة.
- فصل مزود البيانات عن لوحة العرض والمحلل والوكيل الذكي.
- توفير طبقة موحدة للمصادر العامة والمرخصة والخاصة.

### تطبيق Asiri
- `Asiri Data Fabric`: واجهة موحدة للسوق وSupabase وSaxo واللجنة والتنبيهات.
- كل مصدر يعرض حالته وآخر تحديثه ودرجة موثوقيته.
- تعطل مصدر واحد لا يمنع ظهور البيانات المتاحة من المصادر الأخرى.

## 2. Ghostfolio — عدسة الثروة والمخاطر

### المبدأ المفيد
- إدارة أكثر من حساب ومصدر.
- قياس الأداء والتوزيع والمخاطر بدل عرض السعر فقط.
- تصميم مستمر التشغيل ومناسب للهاتف.

### تطبيق Asiri
- قياس قيمة المراكز والتكلفة والربح والخسارة.
- حساب وزن كل مركز وتركيز أكبر مركز.
- إظهار خطر التركيز ضمن قائمة الأولويات.
- الاحتفاظ بملكية المستخدم وخصوصية بيانات المحفظة.

## 3. TradingAgents — أدوار متخصصة وإجماع مفسر

### المبدأ المفيد
- تقسيم القرار بين محللين متخصصين ومدير مخاطر ومدير محفظة.
- إظهار الاختلاف والاعتراض بدل إخفائه داخل نتيجة واحدة.
- بناء سجل قرار قابل للمراجعة.

### تطبيق Asiri
- المحلل الفني، مدير المخاطر، مدير المحفظة.
- حق اعتراض صريح لمدير المخاطر.
- قرار نهائي مفسر مع بوابات شرعية وسعرية ووقف خسارة.
- لا يوجد تنفيذ آلي أو مسار شراء وبيع.

## 4. Microsoft Qlib — الدليل قبل الاعتماد

### المبدأ المفيد
- فصل البيانات والنماذج والاستراتيجية والاختبار والتنفيذ.
- اختبار تاريخي قبل نقل أي استراتيجية إلى الاستخدام الفعلي.
- وحدات مترابطة بصورة ضعيفة ويمكن اختبار كل منها منفردًا.

### تطبيق Asiri القادم
- `Asiri Strategy Lab` لاختبار Golden Alert ودرجات اللجنة تاريخيًا.
- قياس معدل النجاح ومتوسط الربح والخسارة وأقصى سحب.
- منع اعتماد أي قاعدة جديدة دون عينة ونتيجة موثقة.

## 5. MCP — وصول محدود وآمن للمساعد

### المبدأ المفيد
- أدوات وموارد محددة بدل منح الذكاء الاصطناعي وصولًا عامًا.
- تصميم الصلاحيات وفق نموذج تهديد واضح.
- الفصل بين القراءة والكتابة.

### تطبيق Asiri القادم
- `Asiri MCP` للقراءة من حالة المحفظة واللجنة والمطابقة.
- لا مفاتيح وسيط ولا أدوات تداول.
- أدوات صغيرة ومحددة: حالة الوسيط، موجز السوق، نتيجة اللجنة، المطابقة.

## الابتكار الأصلي: Asiri Mission Brief

المشاريع الكبرى تعرض البيانات أو تبني وكلاء أو تقيس المحافظ. ابتكار Asiri هو دمج هذه المكونات في سؤال تنفيذي واحد:

> ما الأولوية الأكثر أهمية الآن، ولماذا، وما الذي يمنع التنفيذ؟

الموجز ينتج أحد الأوضاع التالية:

- `SYSTEM CHECK`: البيانات أو الخدمة غير مكتملة.
- `DEFENSIVE`: حماية رأس المال واعتراض مخاطر أو سوق دفاعي.
- `OBSERVE`: لا توجد إشارة مكتملة.
- `WATCH`: فرصة قوية تحت المراقبة.
- `SELECTIVE`: إعداد مشروط يحتاج إغلاق البوابات.

## حدود الإصدار v6.5

- قراءة وتحليل فقط.
- لا تغيير للمحفظة.
- لا أوامر شراء أو بيع.
- لا فحص شرعي آلي؛ التحقق في عوائد إلزامي.
- الأخبار والأساسيات والاختبار التاريخي مراحل مستقلة لاحقة.
