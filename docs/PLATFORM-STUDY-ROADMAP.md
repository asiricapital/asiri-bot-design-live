# دراسة المشاريع الكبرى وتطبيقها على Asiri Capital

هذه الدراسة تبدأ بعد استقرار v6.4 في الإنتاج. الهدف هو التعلم من البنى الناجحة، لا نسخ المنتجات أو إدخال مكتبات ضخمة بلا حاجة.

## 1. OpenBB — طبقة البيانات القابلة للتبديل

ندرس:

- فصل مزود البيانات عن التحليل والواجهة.
- توحيد النماذج بين الأسعار، الأخبار، الأساسيات، والاقتصاد الكلي.
- إضافة مزود جديد دون تعديل منطق القرار.

المخرج المقترح: `Asiri Data Hub` بواجهات موحدة وميزة fallback بين المزودين.

## 2. Ghostfolio — محاسبة المحفظة والثروة

ندرس:

- العائد المرجح بالوقت والمال.
- الأداء التاريخي والتدفقات النقدية.
- توزيع المحفظة والتركيز والانكشاف.
- الاستيراد والمطابقة وسجل التدقيق.

المخرج المقترح: `Portfolio Intelligence` مع خط أداء، تكلفة حقيقية، سحب أقصى، وتركيز المخاطر.

## 3. TradingAgents — لجنة متعددة الوكلاء

ندرس:

- استقلال الأدوار والتصويت.
- اعتراض مدير المخاطر.
- سجل الأدلة والاختلافات بين المحللين.
- فصل التحليل عن التنفيذ.

المخرج المقترح: تطوير اللجنة من 3 أعضاء إلى 5 بعد اختبار Phase 1، بإضافة الأخبار والأساسيات.

## 4. Microsoft Qlib — مختبر الاستراتيجيات

ندرس:

- الفصل بين التدريب والاختبار خارج العينة.
- منع تحيز النظر للمستقبل.
- قياس معدل النجاح والعائد والسحب والتقلب.
- مقارنة Golden Alert بخط أساس بسيط.

المخرج المقترح: `Asiri Strategy Lab` لاختبار القواعد قبل رفع ثقة التنبيه.

## 5. MCP reference servers — موصل المساعد

ندرس:

- أدوات صغيرة ذات صلاحيات محددة.
- المصادقة وسجلات التدقيق.
- فصل القراءة عن أي عملية كتابة.
- مخطط JSON ثابت للأدوات.

المخرج المقترح: `Asiri MCP Read Only` للمحفظة، حالة الوسيط، المصالحة، المخاطر، والمفضلة.

## 6. Docling + Dify/n8n — منصة المنافسات والعمل

ندرس:

- فهم PDF والجداول والملحقات.
- سير عمل مراجعة بشرية.
- استخراج المتطلبات والمواعيد والتعارضات.
- تحويل البريد والاجتماعات إلى مهام ومتابعات.

المخرج المقترح: `Asiri Tender Intelligence` كمشروع مستقل عن منصة الأسهم.

## معايير قبول أي فكرة

لا تدخل أي فكرة إلى الإنتاج قبل الإجابة عن الأسئلة التالية:

1. هل تحل مشكلة متكررة للمستخدم؟
2. هل يمكن قياس جودتها؟
3. هل تزيد المخاطر الأمنية أو المالية؟
4. هل يمكن تعطيلها أو الرجوع عنها بسهولة؟
5. هل تحتاج مشروعًا مستقلًا بدل تضخيم asiri-bot؟
6. هل الترخيص يسمح باستخدام الكود أم نكتفي بالنمط المعماري؟
