# Asiri Capital v5.8 — Portfolio Reconciliation & Command Center

## الجديد
- مطابقة المحفظة الفعلية مع أرقام الوسيط.
- عداد تعويض الخسارة من قيمة مرجعية قابلة للتعديل.
- أوامر بيع مجدولة مع حالات: معلق، منفذ، ملغي، منتهي.
- منع تجاوز مجموع أوامر البيع للكمية المملوكة.
- فصل التعديل الإداري عن صفقات الشراء والبيع.
- تصحيح صافي الربح لمنع خصم الرسوم مرتين.

## التثبيت
1. نفّذ ملف `supabase_portfolio_command_center_v5_8.sql` في Supabase SQL Editor.
2. ارفع الملفات: `server.js`, `app.js`, `index.html`, `style.css`.
3. أعد النشر في Render.
4. افتح سجل الاستثمار واحفظ أول مطابقة: السيولة 2241.67 ريال، الاستثمارات 2620.46 ريال، المرجع 5010 ريال.
